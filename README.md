# Teste: Qual Monster Você Seria?

Quiz interativo em JavaScript: responda as perguntas e descubra qual Monster você seria.

## Funcionalidades

Sequência de perguntas com base na lógica do quiz. Resultado final mostrando o Monster correspondente às respostas escolhidas.

## Tecnologias utilizadas

HTML5, CSS3 e JavaScript.

## Como executar

Clone este repositório e abra o arquivo index.html no navegador.
